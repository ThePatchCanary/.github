# PatchCanary

Find out what a Windows update broke before you roll it out.

</div>

PatchCanary keeps a page for every Windows KB. Each one has the official release notes, the problems people actually ran into after installing it, and whatever fixed them. If the same issue keeps coming back across different updates, those KBs get linked so you can see it's the same problem and not start from scratch.

If you approve patches for a living, this is for you. Sysadmins, MSPs, help desk. The goal is to make "should I push this update today or wait a week?" an easier call.

## What's in it

Release notes get pulled in as soon as Microsoft publishes them and broken down into fixes, changes and known issues, so you can search them instead of scrolling through a support page.

Anyone can report a problem an update caused and share what fixed it.

There's a public API. Anything you can see on the site, you can query yourself and plug into your own scripts or patch workflow.

## Coverage

Windows comes first. Linux and macOS are on the list after that.

## Status

Still early. The plan is to be fully up and running in early 2027, so expect things to change a lot until then.
